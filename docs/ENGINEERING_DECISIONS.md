Use one entry for each consequential decision, not every small code change.

## Decision 001 — Start with a narrow, deployable interface
**Date:** 2026-10-15  
**Status:** Provisional  
**Context:** SPLASH requires operational evidence. The full recommendation problem is too large to settle up front.  
**Decision:** Investigate a swipe-inspired card and shortlist interface with simple novel selection first.  
**Alternatives:** Begin with advanced personalized recommendations; build a broad multi-media catalogue.  
**Expected benefit:** Faster deployment and earlier user feedback.  
**Risk:** A swipe interface may not improve suitability or efficiency over existing tools.  
**Revisit when:** Initial user observations and comparative tests are available.
