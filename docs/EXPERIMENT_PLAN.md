# First investigation and experiment plan

## Open question
Does card-based browsing help readers find promising web novels more efficiently than an existing discovery workflow?

## Before testing
- Conduct a few exploratory interviews about recent real discovery experiences (without leading users toward the proposed UI).
- Establish whether the problem is finding candidates, assessing suitability, or expressing preferences.
- Specify an appropriate comparison workflow and realistic scope.
- Choose a primary metric and success criterion **before** interpreting results.
- Decide how to handle previously read novels, novel familiarity, task order, and unequal catalogue coverage.
- Provide plain-language consent and avoid storing unnecessary identifiers.

## Candidate measures (not yet final)
Time to first promising novel; number of candidates examined; perceived fit; later reading satisfaction.
