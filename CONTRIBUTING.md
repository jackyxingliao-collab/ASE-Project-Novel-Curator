# Contributing to Novel Curator

## Governance
The project lead sets priorities, assigns issues, and makes final scope and integration decisions. Contributors own the delivery of assigned issues, propose alternatives with evidence, and report blockers early.

## Workflow
1. Take an assigned GitHub Issue and confirm acceptance criteria.
2. Create a branch, e.g. `feat/novel-card` or `research/metadata-sources`.
3. Implement a small change and test it.
4. Open a pull request referring to the Issue.
5. Explain what changed, why, how it was tested, and known limitations.
6. Obtain review before merging to `main` under team policy.

Use clear commits and don't commit secrets or personal research-participant data. Record consequential trade-offs in `docs/ENGINEERING_DECISIONS.md`.
